# Déploiement

Ce dossier accueillera les fichiers Docker Compose et les configurations de déploiement après validation des services réels. Ne fournissez pas encore un fichier de déploiement qui prétend démarrer des composants non implémentés.

Exigences minimales à respecter : utilisateur non-root lorsque possible, images versionnées, secrets injectés hors du dépôt, health checks, limites de ressources, réseau interne et volumes avec permissions contrôlées.
