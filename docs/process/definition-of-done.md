# Definition of Done

Une fonctionnalité n'est terminée que si les éléments applicables ci-dessous sont remplis :

- [ ] Responsabilité du module et contrat d'interface clairement définis.
- [ ] Validation des entrées, erreurs et délais d'expiration traités.
- [ ] Autorisation côté serveur et isolation tenant/actif testées.
- [ ] Données sensibles minimisées, expurgées et protégées.
- [ ] Tests unitaires, d'intégration ou de contrat adaptés ajoutés.
- [ ] Résultats reproductibles et commande de vérification documentée.
- [ ] Journaux utiles sans secrets ni preuves brutes involontaires.
- [ ] Documentation, schémas et exemples mis à jour.
- [ ] CI réussie et pull request revue par le propriétaire du module.
- [ ] Risques résiduels, limitations et exceptions documentés.

Pour une action de réponse : approbation/politique, périmètre, dry-run si pertinent, idempotence, timeouts, audit et résultat vérifié sont requis avant de l'utiliser sur un actif réel.
