# Intégration Nuclei

L'utilisation de Nuclei devra s'appuyer sur une sélection de templates contrôlée, versionnée et revue. Les templates pouvant provoquer des actions actives ou perturber une application sont exclus tant qu'ils n'ont pas été évalués et approuvés.

Toujours valider l'autorisation, les exclusions, les limites de débit et la fenêtre avant d'exécuter un scan. Consigner le commit de templates et la version du scanner dans le résultat.
