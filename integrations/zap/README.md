# Intégration OWASP ZAP

Le connecteur devra sélectionner un profil de scan contrôlé et vérifier l'autorisation du périmètre avant toute opération active. Limiter les requêtes, appliquer les exclusions, journaliser version/configuration, et normaliser les observations vers le contrat de finding.

Commencer par une cible locale ou explicitement autorisée en staging. Ne pas brancher par défaut ce connecteur sur des sites de production.
